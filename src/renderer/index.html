Backup and Restore

Save a copy of the shop database, or restore from a file. Restore is admin only and replaces current data.

Google Drive (Desktop app)

  1. Install Google Drive for Desktop from google.com/drive/download and sign in.
  2. Wait until My Drive appears as a real folder on this PC.
  3. Click Choose Drive folder and pick that folder, or a subfolder such as My Drive/ICAM Backups.
  4. Use Backup to Drive. Drive uploads the file when it is online.

No Drive folder selected.

WhatsApp reminders

  1. Install WhatsApp Desktop or keep WhatsApp on your phone.
  2. Save each customer phone. Local numbers like 0300... are sent as 92... without the leading 0.
  3. Click Remind on WhatsApp on Upcoming Dues, Defaulter list, or a customer. A chat opens with the message filled in. You tap Send.

Placeholders: {name} {account} {amount} {due_date} {shop}
